Getting Started

Use Menu Items to add, edit or remove dishes, change prices, mark items as Best Seller or Chef Special, and toggle availability. Use Categories to rename or add new sections. When you're happy with your changes, open Import / Export to download an updated menu.json and commit it to your GitHub repository — that's what keeps the change permanent for every visitor, since localStorage only lives in this browser.
